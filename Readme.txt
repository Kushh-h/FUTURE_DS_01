 Superstore Sales Performance Analysis

 Task Information

Track Code: DS

Repository Name: FUTURE_DS_01

 Project Objective:

This project analyzes sales performance using the Superstore dataset. The objective is to identify revenue trends, top-performing products, profitable categories, and high-value regions to support business decision-making.

 Tools Used:

* Power BI
* Microsoft Excel
* GitHub

Dashboard Features:

* KPI Cards (Sales, Profit, Orders, Quantity)
* Revenue Trend Analysis
* Sales by Category
* Sales by Region
* Profit by Region
* Top 10 Sub-Categories
* Sales vs Profit Analysis
* Interactive Filters

Key Insights:

* Technology generated the highest sales revenue.
* The West region was the strongest performing region.
* Phones and Chairs were among the top-selling sub-categories.
* Sales showed consistent growth over the analyzed period.

 Business Recommendations:

* Increase investment in high-performing product categories.
* Replicate successful strategies from top-performing regions.
* Optimize discount strategies to improve profitability.
* Focus marketing efforts on high-demand products.

Files Included:

* Cleaned Dataset
* Power BI Dashboard
* Dashboard Screenshots
* Business Insights Report
